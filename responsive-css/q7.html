Responsive Design

Responsive web design allows a website to adapt to different screen sizes. Flexbox, CSS Grid and media queries help create layouts that work on desktops, tablets and mobile devices.

CSS Cheat Sheet

Flexbox → Flexible layouts

Grid → Row and column layouts

Media Queries → Responsive design

Clamp() → Responsive font sizes
